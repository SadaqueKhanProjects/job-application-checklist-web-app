# Project instructions

- Keep this project free to use and maintain. Use free tools and services; do not introduce paid subscriptions, paid APIs, paid hosting, or usage that can incur charges. A free tier with billable overages is not by itself a zero-cost guarantee. Follow a later explicit user instruction if this constraint is changed.
- Keep application data and screenshot recognition on the user's device unless the user explicitly changes the privacy requirements. Do not silently add accounts, telemetry, remote OCR or external content services.
- This repository is public with owner approval. Use only standard free GitHub-hosted runners, without Actions artifact uploads, caches or paid services. CI is gated off for private repositories. If visibility changes back to private, verify an effective hard spending block before enabling metered workflows; otherwise run checks locally.
- Do not change account-wide billing or payment settings, change repository visibility, or affect sibling projects as a workaround. Ask the user if any such change is needed.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for the repository's issue, branch, validation and PR workflow. Preserve existing user data and checkout changes.
